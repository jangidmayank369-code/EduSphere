\# EduSphere Backend



Production-grade backend API for EduSphere — a modern School Operating System.



\## Technology Stack



\- Python 3.13+

\- FastAPI

\- SQLAlchemy

\- PostgreSQL

\- Psycopg

\- Alembic

\- Pydantic Settings

\- Pytest
